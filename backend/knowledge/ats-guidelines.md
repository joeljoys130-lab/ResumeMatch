# ATS (Applicant Tracking Systems) Optimization Guidelines

## 1. ATS Parsing Fundamentals
Applicant Tracking Systems parse resumes into plain text fields before human recruiters review them.
- Avoid multi-column layouts, tables, text boxes, and complex graphical graphics which disrupt text extraction parsers.
- Use standard section headings: "Work Experience", "Education", "Skills", "Projects".

## 2. Keyword Alignment and Density
- Match exact key terms listed in the target Job Description (e.g. if the JD asks for "PostgreSQL", write "PostgreSQL" rather than just "SQL").
- Integrate technical keywords naturally into action bullet points under Experience, rather than solely piling them in a skill list.

## 3. File Formats and Compatibility
- Clean, text-based PDF documents exported directly from Word or Google Docs work best.
- DOCX files are universally parseable by legacy ATS engines.
