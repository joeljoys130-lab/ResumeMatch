# Comprehensive Resume Writing Guide

## 1. Executive Summary & Impact-Driven Bullets
Your resume should immediately demonstrate quantifiable business impact. Avoid generic responsibility descriptions such as "Responsible for building web components." Instead, use the Action Verb + Context + Quantified Outcome formula:
- Example: "Architected micro-frontend architecture using React and Vite, reducing initial page bundle size by 35% and improving lighthouse performance score from 68 to 94."

## 2. Structure and Layout
- Keep length to 1 page for early-career (0-5 years) or 2 pages maximum for senior candidates (6+ years).
- Structure sections logically: Header/Contact, Professional Summary, Technical Skills, Experience, Projects, Education.
- Maintain consistent spacing, bullet points, and typography.

## 3. Highlighting Core Technologies
- Categorize technical skills clearly: Languages (JavaScript, Python), Frameworks (React, Node.js, Express), Databases (PostgreSQL, MongoDB), Infrastructure/Tools (Docker, Redis, Git).
- List technologies in order of mastery and relevance to target roles.
